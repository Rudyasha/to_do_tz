## Контекст

Todo-приложение использует JSONPlaceholder. Основной пользовательский путь: **создание → редактирование → изменение статуса → фильтрация → удаление**.

Документация подготовлена на основе предоставленного текста. Неподтверждённые ограничения и отсутствующие доказательства отмечены в соответствующих разделах. Исходный код тестируемого приложения, Postman-коллекция и вложения к багам в этот репозиторий не предоставлены.
